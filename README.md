# 매장 매니저 (Store Manager)

소상공인 매장의 **매출과 생산성을 높이기 위한** Flutter 안드로이드 앱입니다.
계산대(POS) 주문, 재고 관리, 매출 통계를 한 앱에서 처리하고,
판매 기록을 분석해서 매출을 늘릴 수 있는 제안을 자동으로 보여줍니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 홈 | 오늘 매출·순이익·주문 수·객단가, 어제 같은 시간과 비교, 최근 7일 매출 차트, 재고 부족 알림, 매출 향상 팁 |
| 주문 | 분류별 메뉴 선택 → 장바구니 → 결제 수단(카드/현금/계좌이체) 선택 → 결제할 때 재고 자동 차감 |
| 상품 | 상품 등록·수정·삭제, 원가 입력과 마진율 계산, 입고 처리, 재고 부족 상품만 보기 |
| 통계 | 오늘/7일/30일 매출, 직전 기간 대비 증감, 일별·시간대별 매출 차트, 상품별 판매 순위, 결제 수단 비중 |
| 내역 | 최근 30일 주문 기록과 일별 매출, 주문 상세, 환불 처리(재고 복원) |

### 매출·생산성 향상 포인트

- **원가 기반 순이익**: 매출만이 아니라 원가를 뺀 실제 이익과 이익률을 보여줍니다.
- **자동 인사이트**: 매출 증감, 손님이 몰리는 시간대, 이익 1위 메뉴, 판매 부진 메뉴, 재고 부족을 분석해 할 일을 제안합니다.
- **재고 자동 관리**: 결제하면 재고가 줄고 환불하면 되돌아와서, 따로 재고를 셀 일이 줄어듭니다. 재고가 모자라면 결제 자체를 막습니다.
- **공정한 비교**: 진행 중인 오늘 매출은 "어제 하루 전체"가 아니라 "어제 같은 시각까지"와 비교합니다.

## 기술 스택

- Flutter / Dart 3
- [sqflite](https://pub.dev/packages/sqflite): 기기 내부 SQLite 저장 (서버 없이 동작)
- [fl_chart](https://pub.dev/packages/fl_chart): 매출 차트
- [intl](https://pub.dev/packages/intl): 금액·시간 표시
- 상태 관리: `ChangeNotifier` + `InheritedNotifier` (외부 라이브러리 없음)

## 폴더 구조

```
lib/
├── main.dart                 # 앱 시작, 하단 탭 5개
├── models/                   # Product, SalesOrder, OrderItem
├── data/app_database.dart    # SQLite 테이블, 주문·환불 트랜잭션, 데모 데이터
├── logic/sales_stats.dart    # 매출 집계·순위·인사이트 계산 (UI와 분리, 단위 테스트 대상)
├── state/app_state.dart      # 상품 목록·장바구니 상태
├── screens/                  # 홈, 주문, 상품, 상품 편집, 통계, 내역 화면
├── widgets/common.dart       # 통계 카드, 막대 차트 등 공용 위젯
└── utils/format.dart         # 금액·날짜 표시
test/
└── sales_stats_test.dart     # 매출 계산 단위 테스트
```

## 설계에서 신경 쓴 점

- 주문 항목에 **주문 당시의 상품명·가격·원가를 저장**합니다. 나중에 가격을 바꾸거나 상품을 지워도 과거 매출이 변하지 않습니다.
- 재고 확인 → 재고 차감 → 주문 저장을 **하나의 트랜잭션**으로 처리해서, 중간에 실패해도 재고와 주문이 어긋나지 않습니다.
- 처음 실행하면 **카페 메뉴 11종과 최근 30일 주문 데이터**를 만들어서, 설치하자마자 통계를 확인할 수 있습니다.

```bash
flutter build apk         # APK 빌드 → build/app/outputs/flutter-apk/app-release.apk
```
